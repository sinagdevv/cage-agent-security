# Threat Model Research

Formal definitions of threats against autonomous AI agent systems.

## Primary Threat Classes

1. **Context & Prompt Injections (Direct & Indirect)**: Injection of instructions altering agent objectives.
2. **Confused Deputy Exploits**: Misuse of authorized tool capabilities due to external or untrusted influence.
3. **Chain Fragmentation**: Evading single-step policies through temporal or functional decomposition.
4. **Side-Channel Exfiltration**: Leaking confidential context through legitimate tool arguments.
5. **Delegation Spoofing**: Impersonation or malicious parameter tampering in multi-agent handoffs.
